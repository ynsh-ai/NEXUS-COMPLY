# NEXUS-COMPLY Backend

> AI-Powered Multi-Vendor Network Security Compliance Platform — Complete Package B (Non-Cyber APIs)

NEXUS-COMPLY is an automated compliance and cybersecurity auditing engine. This repository houses the unified Spring Boot REST API application covering **all 92 specified endpoints (B-001 through B-092)** across 13 core domain modules.

---

## Architecture Overview

The backend is built with **Spring Boot 3.3.4** and **Java 25 LTS** (targeting release 17). It adopts a clean domain-driven package structure:

```text
com.nexuscomply
├── parser          (B-001 – B-004) -> Async parsing of vendor configurations
├── normalization   (B-005 – B-008) -> Canonical state normalization & source line maps
├── framework       (B-009 – B-016) -> Compliance frameworks, controls, rules & cross-mappings
├── audit           (B-017 – B-027) -> Audit execution, lifecycle, results, risk & reports
├── compliance      (B-028 – B-033) -> Rule evaluation against configurations & controls
├── finding         (B-034 – B-045) -> Findings lifecycle, status/severity updates & evidence
├── risk            (B-046 – B-052) -> Device/finding risk profiles, trends & recalculation
├── drift           (B-053 – B-058) -> Configuration drift detection, comparison & control impact
├── simulation      (B-059 – B-063) -> What-If simulations, reruns & impact forecasting
├── remediation     (B-064 – B-070) -> Templates, remediation plans, validation & verification
├── ai              (B-071 – B-079) -> Async AI analysis, rule mappings & approval workflows
├── dashboard       (B-080 – B-086) -> Aggregated overview metrics, compliance & activity feeds
├── report          (B-087 – B-092) -> Report generation, previews, binary downloads & regeneration
└── common
    ├── api         -> Standard ApiResponse<T>, PageResponse<T>, ErrorResponse
    ├── config      -> CorsConfig for frontend integration
    ├── exception   -> GlobalExceptionHandler, ApiException, ResourceNotFoundException
    └── security    -> SecurityConfig, RequestIdFilter (REQ-xxxxxxxx)
```

## How to Build and Run

### 1. Environment Setup

Configure your environment variables for Java and Maven:

```bash
export JAVA_HOME="/Library/Java/JavaVirtualMachines/temurin-25.jdk/Contents/Home"
export PATH="/Users/mac/.maven/apache-maven-3.9.9/bin:$JAVA_HOME/bin:$PATH"
```

### 2. Compile and Test

```bash
# Compile all source classes
mvn clean compile

# Run the complete automated test suite (16 tests across all domains)
mvn test
```

### 3. Run the Backend

```bash
mvn spring-boot:run
```

Once running:
* **Interactive Swagger UI:** [`http://localhost:8080/swagger-ui.html`](http://localhost:8080/swagger-ui.html)
* **OpenAPI 3.0 JSON:** [`http://localhost:8080/v3/api-docs`](http://localhost:8080/v3/api-docs)
